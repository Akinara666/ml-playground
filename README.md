# ML Playground

Учебно-практический сборник моделей машинного обучения. Репозиторий служит площадкой для отработки базовых алгоритмов и методик анализа данных с упором на объяснимость и воспроизводимость.

## Структура
- `linear_regression/` — ноутбук и README по линейной регрессии на датасете California Housing.
- `requirements.txt` — фиксированный список зависимостей для работы с ноутбуками.

## Модули
### Linear Regression
- Ноутбук `linear_regression/notebook.ipynb` показывает весь цикл: первичный анализ признаков и целевой переменной, бейзлайн на `DummyRegressor`, линейную регрессию со стандартизацией признаков, оценку по MAE и R², интерпретацию коэффициентов и анализ ошибок.
- README в каталоге описывает логику эксперимента и основные выводы.
