# Decision Tree: Breast Cancer Diagnosis

Пример интерпретируемой классификации на датасете Breast Cancer Wisconsin. Ноутбук показывает полный процесс: исследование данных, обучение решающего дерева, оценку метрик и разбор структуры дерева.

## Что такое решающее дерево и зачем оно нужно
Решающее дерево рекурсивно разбивает пространство признаков на области, задавая правила вида «если признак ≥ порога, то...». Каждый лист соответствует классу, а вероятность рассчитывается по статистике объектов в листьях.
- Понятные правила: легко объяснить врачу, почему модель сделала предсказание.
- Работа с несбалансированными шкалами признаков без предварительного нормирования.
- Базовый строительный блок для ансамблей (Random Forest, Gradient Boosting), поэтому важно понять одиночное дерево.

## Датасет
- Источник: `sklearn.datasets.load_breast_cancer`.
- 30 числовых признаков, извлечённых из изображений биопсий.
- Классы: `0` — malignant (злокачественная), `1` — benign (доброкачественная).

## Что происходит в ноутбуке
- **Загрузка и EDA:** описательные статистики и корреляции признаков, анализ долей классов.
- **Модель:** `DecisionTreeClassifier` с ограничением глубины и минимальным размером листа для интерпретируемости.
- **Метрики:** accuracy, precision, recall, F1 и ROC-AUC с акцентом на распознавание класса `malignant`.
- **Визуализация:** матрица ошибок, ROC-кривая, таблица важности признаков, горизонтальная диаграмма топ-10 и визуализация верхних уровней дерева.
- **Интерпретация:** текстовые комментарии по метрикам, ошибкам и ключевым признакам.

## Почему выбран набор метрик
- **Recall (malignant)** — критичен: отражает долю найденных злокачественных опухолей.
- **Precision (malignant)** — снижает количество ложных тревог и ненужных обследований.
- **F1** — баланс между precision и recall, полезен при несбалансированных данных.
- **ROC-AUC** — показывает, насколько хорошо дерево ранжирует объекты по вероятности злокачественности.
- **Accuracy** — даёт общую картину, но рассматривается вместе с предыдущими метриками.

## Результаты и выводы
- Ограниченное по глубине дерево обеспечивает высокую полноту и точность по классу `malignant`.
- Важность признаков подчёркивает роль показателей «worst» (наихудшие значения измерений) в диагностике.
- Структура дерева задаёт простые правила, пригодные для обсуждения с доменными экспертами.
